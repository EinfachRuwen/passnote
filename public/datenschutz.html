2. Was PassNote speichert

Blöcke. Wenn du einen Block anlegst, speichere ich auf meinem Server den zufällig erzeugten Code (z. B. calm-moon-42), den Zeitpunkt der Erstellung und der letzten Aktivität und, falls du eins vergibst, das Passwort des Blocks. Das Passwort wird nur als Hash (bcrypt) gespeichert, nie im Klartext.

Zettel. Zu jedem Zettel speichere ich, was du getippt oder mit dem Stift geschrieben hast (Text bzw. Strichdaten), den Anzeigenamen, den du eingibst (höchstens 20 Zeichen), eine zufällige Kennung deines Geräts, die zugeteilte Farbe und die Uhrzeit. Pro Block bleiben die neuesten 150 Zettel erhalten; ältere fallen automatisch heraus. Eigene Zettel kannst du jederzeit wegwerfen (lange drücken oder Rechtsklick), dann werden sie aus dem Block entfernt.

Wer das sieht. Alle, die gerade im selben Block sind oder ihn später öffnen, sehen die Zettel mit deinem Anzeigenamen. Solange du im Block bist, sehen sie außerdem deinen Namen in der Teilnehmerliste und den Hinweis „… schreibt“. Einen Block ohne Passwort kann jede Person öffnen, die den Code kennt oder errät. Die Codes sind kurz; für alles, was nicht jeder lesen soll, nutze bitte ein Passwort.

Die Zettel liegen nicht Ende-zu-Ende verschlüsselt auf meinem Server. Als Betreiber kann ich Blöcke über einen Admin-Bereich ansehen, leeren und löschen.

Bitte gib keinen vollständigen Namen und keine sensiblen Daten ein. Ein Vorname oder Spitzname reicht.

Rechtsgrundlage ist Art. 6 Abs. 1 lit. b DSGVO: Ohne diese Daten kann PassNote keine Zettel zwischen euch weitergeben.

3. Wann gelöscht wird

Blöcke, die sieben Tage lang nicht benutzt wurden, werden mit allen Zetteln automatisch gelöscht. Als Benutzung zählt, wenn jemand einen Zettel schreibt oder wegwirft oder den Block nach einem Besuch wieder verlässt. Die Prüfung läuft einmal pro Stunde; ein Block, in dem gerade jemand ist, wird nicht gelöscht.

Ausnahme: Blöcke, die ich selbst im Admin-Bereich als „dauerhaft“ anlege, werden nicht automatisch gelöscht, sondern erst, wenn ich sie lösche.

Wenn du möchtest, dass ein Block früher verschwindet, schreib mir den Code an die oben genannte E-Mail-Adresse.

4. Server, Cloudflare und Protokolle

Eigener Server. PassNote läuft auf meinem eigenen Server. Dort liegen die Datenbank mit den Blöcken und Zetteln.

Cloudflare. Die Verbindung zu PassNote, einschließlich der Live-Verbindung für die Zettel (WebSocket), wird über Cloudflare Inc., 101 Townsend St, San Francisco, CA 94107, USA, geleitet (Cloudflare Tunnel). Die verschlüsselte HTTPS-Verbindung endet dabei bei Cloudflare und wird von dort an meinen Server weitergeleitet. Cloudflare verarbeitet dabei deine IP-Adresse, Datum und Uhrzeit, die aufgerufene Adresse (darin auch der Code eines Blocks), Browser- und Systemangaben und leitet die übertragenen Inhalte durch. Das ist nötig, damit PassNote sicher erreichbar ist, ohne dass mein Server direkt aus dem Internet erreichbar sein muss, und um Angriffe abzuwehren (Art. 6 Abs. 1 lit. f DSGVO). Cloudflare ist unter dem EU-US Data Privacy Framework zertifiziert (Art. 45 DSGVO).

Protokolle auf meinem Server. PassNote selbst schreibt keine Zugriffsprotokolle mit IP-Adressen. Um Missbrauch zu bremsen, merkt sich der Server deine IP-Adresse kurz im Arbeitsspeicher und zählt deine Anfragen (höchstens 300 in 15 Minuten); nach Ablauf des Zeitfensters oder bei einem Neustart ist das vergessen (Art. 6 Abs. 1 lit. f DSGVO). Betriebsmeldungen wie Start, Fehler und Löschläufe (mit dem Code gelöschter Blöcke) landen ohne IP-Adresse in einem Protokoll, das automatisch überschrieben wird.
